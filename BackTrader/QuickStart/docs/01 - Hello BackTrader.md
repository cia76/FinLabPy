Обычно, в первом примере идет подключение к системе и выполнение простейшей операции. Такой пример называется "Привет, мир" или "Hello world". Сделаем такой пример и мы для BackTrader.

Импортируем библиотеку через команду:

```python
import backtrader as bt  # Библиотека BackTrader
```

В курсе все примеры будем запускать из скриптов Python. Обозначим точку входа для запуска скрипта.

```python
if __name__ == '__main__':  # Точка входа при запуске этого скрипта
    pass  # Эту строчку заменим в будущем на код
```

Для сборки и запуска торговых систем в BackTrader есть "движок", который называется Cerebro. Инициируем его.

```python
    cerebro = bt.Cerebro()  # Инициируем "движок" BackTrader (Cerebro = Мозг на испанском)
```

В этом примере мы будем работать с "бумажным" брокером. Это означает, что заявки не будут отправляться черерз брокера на биржу.

По умолчанию, стартовый капитал "бумажного" брокера составляет 10 000 единиц. Но его можно изменить. Например, поставить 1 000 000 единиц.

Чтобы лучше читать числа в Python, можно использовать нижнее подчеркивание для разделения разрядов. Согласитесь, что 1_000_000 читается гораздо лучше, чем 1000000.

```python
    cerebro.broker.setcash(1_000_000)  # Стартовый капитал для "бумажной" торговли (по умолчанию, 10_000)
```

Проверим, что значение "бумажного" счета изменилось. Для этого в BackTrader есть функции получения свободных средств **cerebro.broker.getcash()** и стоимости портфеля (позиций) **cerebro.broker.getvalue()**.
Напишем функцию, которая будет получать эти значения и выводить их на экран.

```python
def get_cash_value():
    cash = cerebro.broker.getcash()  # Свободные средства
    value = cerebro.broker.getvalue()  # Стоимость портфеля
    print(f'Свободные средства : {cash}')
    print(f'Стоимость позиций  : {value - cash}')
    print(f'Стоимость портфеля : {value}')
```

Из основного скрипта вызовем эту функцию.

```python
    print('\nСтартовый капитал')
    get_cash_value()  # Отображаем статистику портфеля до запуска ТС
```

Мы видим, что стартовый капитал для "бумажной" торговли именно тот, что задали.

В "движке" BackTrader мы должны собрать все компоненты торговой системы, что будем запускать. Кроме брокера, мы можем указать источник исторических данных, торговую систему, лот, комиссии, анализаторы и многое другое.
В дальнейших примерах мы разберем эти компоненты подробнее. Сейчас просто запустим "движок".

```python
   cerebro.run()  # Запуск ТС. Пока ее у нас нет
```

Пока у нас нет торговой системы, поэтому даже "бумажных" сделок не будет. Значит, если после запуска снова вызвать функцию получения свободных средств и стоимости портфеля, то значения не должны изменяться.

Полный код примера:

```python
import backtrader as bt  # Библиотека BackTrader


def get_cash_value():
    cash = cerebro.broker.getcash()  # Свободные средства
    value = cerebro.broker.getvalue()  # Стоимость портфеля
    print(f'Свободные средства : {cash}')
    print(f'Стоимость позиций  : {value - cash}')
    print(f'Стоимость портфеля : {value}')


if __name__ == '__main__':  # Точка входа при запуске этого скрипта
    cerebro = bt.Cerebro()  # Инициируем "движок" BackTrader (Cerebro = Мозг на испанском)
    cerebro.broker.setcash(1_000_000)  # Стартовый капитал для "бумажной" торговли (по умолчанию, 10_000)
    print('\nСтартовый капитал')
    get_cash_value()  # Отображаем статистику портфеля до запуска ТС
    cerebro.run()  # Запуск ТС. Пока ее у нас нет
    print('\nКонечный капитал')
    get_cash_value()  # Отображаем статистику портфеля после запуска ТС
```
