Для начала, давайте подготовим рабочее место для работы с курсом. Вам понадобятся:
- Установленный [Python](https://python.org) версии 3.12 и выше
- Установленные и настроенные библиотеки-обертки *Py для ваших брокеров. [Все они находятся здесь >>>](https://github.com/cia76/)
- Установленная и настроенная универсальная система автоторговли "Финансовая Лаборатория" [FinLabPy](https://github.com/cia76/FinLabPy)
- Установленная библиотека BackTrader. Установить её можно через терминал/командную строку

```bash
pip install backtrader
 ```
