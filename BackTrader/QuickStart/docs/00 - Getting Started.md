Для начала, давайте подготовим рабочее место для работы с курсом. Вам понадобятся:
- [Python](https://python.org) версии 3.12 и выше
- Установленная и настроенная универсальная система автоторговли "Финансовая Лаборатория" [FinLabPy](https://github.com/cia76/FinLabPy) с коннекторами к вашим брокерам
- Установленная библиотека BackTrader. Установить её можно через терминал/командную строку

```bash
pip install backtrader
 ```
